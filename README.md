# 中式八球 · 网页版

用 HTML5 Canvas + 原生 JavaScript 实现的中式八球小游戏，支持双人对战、人机对战、自由力度、加塞、开球摆球与犯规自由球。

## 在线游玩

打开 GitHub Pages 链接即可：

`https://zrm912.github.io/billiards/`

## 操作

- **瞄准**：鼠标或手指在台面移动 / 拖动。
- **力度**：拖动“击球力度”滑杆自由选择，按 `↑` / `↓` 也可微调。
- **击球**：点击“击球”按钮或按 `空格`。
- **角度微调**：拖拽右下角旋钮，或按 `←` / `→`。
- **加塞**：在“母球加塞”圆盘上点击或拖动。
- **开球 / 自由球**：拖动白球或点击台面合法位置摆放。
- **手机**：支持触屏拖动瞄准；点击右上角“全屏”进入专注模式，横屏体验更佳。

## 技术要点

- 固定物理步长 `1/120s`，包含摩擦、库边反弹、球球碰撞与加塞弯曲。
- AI 会枚举目标球与袋口，检测两条路径是否畅通，并按难度加入瞄准扰动。
- 开球前和犯规后进入自由摆球状态。
- Canvas 缓存台呢噪点纹理、木质/金属分层、袋口黄铜圈，以及粒子、扩散环、浮动文字和屏幕震动特效。
